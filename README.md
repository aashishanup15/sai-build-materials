# Sai Build Materials

Website for **Sai Arnab Constructions** and **Sai Anshruta Constructions**, supplying cement, TMT bars and construction materials around Kuanpal, Mahanga and Cuttack, Odisha.

## Website

https://aashishanup15.github.io/sai-build-materials/

## Features

- ACC, UltraTech and Ambuja product ranges with manufacturer application links.
- Scroll-sensitive horizontal cement and TMT product sections.
- TMT diameter comparisons, approximate weights, grade selection and brochure.
- Responsive layouts, keyboard controls and reduced-motion support.
- Symmetric dealership panels and a locally prepared enquiry message.

## Edit and preview

This is a static HTML/CSS/JavaScript website; no build step or package installation is needed. Edit index.html, trade.css and scenes/. Product images and the brochure are in assets/.

Preview with any static web server, for example:

```sh
python -m http.server 4173
```

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, **main**, **/(root)**, then Save. The .nojekyll file serves these static files without Jekyll processing. All internal asset links are relative, supporting the project subpath.

## Business contact status

The enquiry form currently prepares a message locally and offers a copy button. It does not send messages or save enquiries. A confirmed business phone/WhatsApp contact is still needed. Rates, stock and delivery terms must be confirmed with the dealership.
